# Всё в одном

Личное Android-приложение: часы, будильник, таймер, погода, калькулятор, рандом, копилки, вес — и дальше по плану.

## Как установить на телефон
1. Открой на телефоне страницу **Releases** этого репозитория.
2. Скачай последний файл `.apk`.
3. Открой его, разреши установку из этого источника, нажми «Установить».
Обновления ставятся поверх, данные сохраняются.
