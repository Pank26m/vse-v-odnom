# Заметки для работы над проектом

- Владелец не программист. Общение на русском, прямо, без воды.
- Язык интерфейса — русский. Исходные данные (СМС, расписание пар на украинском) не переводить.
- Стек: Kotlin, Jetpack Compose (Material3), Room (KSP), один модуль `app`. minSdk 29, target 35. Телефон владельца — Pixel 8 Pro.
- Дизайн: светлый, пастельный; палитра и компоненты — `ui/theme/Theme.kt`, `ui/common/Common.kt`. Шрифт Manrope (вариативный).
- Сборка локально: Android SDK в `/opt/android-sdk` (ставится через cmdline-tools), `./gradlew assembleDebug --max-workers=1` (Maven Central через прокси отдаёт 429 при параллельных загрузках — повторять).
- Релизы: GitHub Actions (`.github/workflows/build.yml`) собирает release APK, подписывает ключом из секретов и публикует в Releases. Ключ подписи нельзя терять — иначе обновление не встанет поверх.
- Файл расписания (ACY Portal, .xls) слегка битый — стандартные парсеры падают; нужен терпимый разбор. Структура: строка дня (Пн + даты недель по столбцам), затем строки «N пара\nHH:MM-HH:MM» с ячейками «Предмет [Лк/Пз]\nауд. X\nПреподаватель».
- Версии, которые упираются в тулчейн (AGP 8.7.3, compileSdk 35): health connect-client 1.1.0-alpha11 (новее требуют AGP 8.9+ и SDK 36), youtubedl-android (io.github.junkfood02) 0.17.4. Обновлять — только вместе с AGP.
- Сборка только под arm64-v8a (yt-dlp + ffmpeg занимают ~28 МБ нативных библиотек), jniLibs.useLegacyPackaging = true обязательно.
- База Room: версия 8, миграции M1_2 … M7_8 в `data/Db.kt` (сущности v4 — `data/Db4.kt`), схемы в `app/schemas`. Любое изменение сущностей = новая миграция, иначе у владельца пропадут данные. Проверка: `python3 -I tools/check_migration.py app/schemas/com.pank.vsevodnom.data.AppDb app/src/main/java/com/pank/vsevodnom/data/Db.kt 8`.
- Подпись: ключ владельца (alias `vse`) у него на руках; секреты GitHub (`SIGNING_*`) записать из сессии нельзя — их добавляет владелец. Без ключа новая версия не встанет поверх.
- Тесты логики (JVM): `ScheduleParserTest` (нужен SCHEDULE_XLS), `ChessTest` (perft), `GamesTest`, `TotpTest`, `SmsCodeTest`, `CalcTest` (+`MathEditorTest`), `ImportTest` (+Sumlio/вес через SUMLIO_CSV/WEIGHT_CSV), `HolidayTest`, `PushParseTest`. Robolectric убран — прокси не отдаёт android-all jar.
- Регэкспы: на Android движок ICU — флаг `(?U)` там НЕ работает и роняет приложение (так падало окно пары в 0.8). Тест `RegexSafetyTest` это ловит. Для кириллицы не полагаться на `\b`/`\w` — писать явные классы символов.
- Миграции Room проверять скриптом: создать БД по N.json, применить SQL миграции, сравнить PRAGMA table_info/index_list с (N+1).json (так проверена M2_3).
- Диалоги пишут в БД через `AppScope.io`, не через rememberCoroutineScope диалога — иначе запись отменяется при закрытии.
- Не проверено на устройстве: формат ответа ubilling.net.ua (тревоги), Yahoo Finance, YASNO (`data/Power.kt`), поиск по сайту КНУБА (`wp-json/wp/v2/search`), формат push банков (`data/NotifListener.kt`, `PushParse`) — из сессии хосты недоступны.
- Капри удалён в 0.8. Главная — как «Київ Цифровий»: кружки статуса (погода, свет, тревога), выбираемые плитки (`HomeTiles`), «Сводка».
- Разделы v0.8: Дела (`ui/todo`), Деньги (`ui/money`, `data/Money.kt`: импорт Sumlio, mono API, курсы НБУ), Свет (`data/Power.kt`), Карта (`ui/map`, osmdroid 6.1.20; поиск — Nominatim, не чаще 1 запроса/с; треки — `data/Geo.kt` TrackService, каждый трек = событие календаря).
- Уведомления других приложений: `NotifListener` — только коды из почты (показ в СМС → «Коды»). Банки/mono убраны по просьбе владельца: расходы вводятся вручную. Для сторонней установки Android 13+ требует «Разрешить ограниченные настройки».
- Резервная копия всего — `data/Backup.kt` (zip: база, настройки, files/ без vault.*). Пароли — только своим бэкапом: ключ в Keystore не переносится. Автокопия Android тоже исключает vault.* (`res/xml/*backup*`).
- Калькулятор — двумерный редактор формул `MathEditor` (дерево MRow/MFrac/MSup/MRoot/MFunc/MAbs → линейная строка → `Expr`/`Solver`).
- v0.9: «Финансы» (`ui/money`) — по образцу приложения владельца: свой нижний бар (Счета/Категории/Операции/Статистика/Больше), плитки категорий со значками (`CatIcons.kt`, ключ в Category.icon, цвет — индекс CAT_COLORS). Главный нижний бар на этом экране скрыт.
- «Дела» — плитки: Задачи (`Tasks.kt`, окно как в TickTick, фильтры), Привычки (`Habits.kt`, галерея + редактор, напоминания `HabitReminders`), Списки (`Lists.kt`: страницы list_page — MOVIES/SHOP/NOTES; заметки с разметкой `RichText.kt`), Даты (`Dates.kt`). Фокус — вкладка в «Часах» (`ui/clock/Focus.kt`).
- Фильмы: `data/Movies.kt` — Викиданные (поиск/данные), Википедия (описание/постер), IMDb suggestion API (постер) и страница IMDb (оценка). Ключи не нужны; из сессии не проверено.
- Плашка «нет интернета» — `data/Net.kt` + `OfflineBanner`; загрузки при офлайне показывают крутилку (`NetWait`).
- «Как я проживаю жизнь» — `ui/health/LifeScore.kt`: взвешенная оценка по сторонам, где есть данные.
- v0.10: раздел называется ToDo. Плитки: Задачи, Привычки, Заметки (`Notes.kt`: архив, корзина 60 дней, вложения в Note.attachments JSON — фото/голос/рисунки/место), Фильмы (`Lists.kt`), Покупки (`Shop.kt`: несколько списков, перетаскивание за ручку, порядок = ListEntry.sort), Даты (`Dates.kt`: кубик подарков, импорт дней рождения из контактов по выбору, Birthday.contactKey), Статистика (`Stats.kt`). Под плитками — лента незавершённого с ярлыками.
- Стиль ToDo — свой, не копия TickTick: `TodoCommon.kt` (CheckCircle с анимацией, Leaving — плавное исчезновение выполненного, StreakFlame, FormCard, ChoiceGrid, PriorityDots, RichField). Приоритет: 1 зелёный, 2 жёлтый, 3 красный.
- v0.11: аркады в «Играх» — свои названия и вид (не копии оригиналов): Слияние (`Merge.kt`, 2048-механика), Змейка, Лабиринт (`Maze.kt`, своя карта MAZE_MAP), Клетки (`Cells.kt`), Крестики-нолики (минимакс), Территории (`Territory.kt`, правила боя кубиками описаны в KDoc). Общее — `Arcade.kt` (GameLoop, рекорды Hi, GameOverlay).
- v0.12 (основы, развивать дальше): Команды (`data/Commands.kt` — цепочки действий в prefs JSON, ярлык на рабочий стол через extra "command"), Музыка (`data/Music.kt`: MediaStore + Player + MusicService с MediaSession), Коды (`ui/codes`: сканер — Google code scanner из Play Services, без разрешения камеры; генерация — ZXing; печать — PdfDocument), PDF (`data/PdfTools.kt` на PDFBox-Android: страницы правятся без растрирования, рисунок — прозрачный слой поверх; конвертации — свои минимальные DOCX/XLSX), Архивы в Утилитах (`ui/files/Archive.kt`: zip/tar/gz — commons-compress, rar — junrar, RAR5 не читается), Карточки и Английский (`ui/learn/Learn.kt`, `data/Flashcards.kt`; база v7: deck/card, повторение по Лейтнеру; словарь — assets/en/*.txt «слово|перевод», 4049 слов, тест `Round6Test.englishDictionary`).
